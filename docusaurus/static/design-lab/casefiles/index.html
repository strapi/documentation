Plain words, no fedora

This is the real Strapi documentation (docs.strapi.io), dressed up as a detective agency. Nothing on these walls is invented; every number is measured from the actual docs and their git history.

A case fileOne real documentation page, fully readable here. 290 in total.
The corkboardA map of the whole documentation. Each pin is a page; districts (“precincts”) are the sidebar sections.
Red stringA real cross-reference: one page linking to another. There are 1,231 of them.
CASE No.A stable number derived from the page’s address. Same page, same number, always.
OPENED / LAST SEENThe real dates of the page’s first and most recent git commits.
WITNESSESThe real people who committed changes to that page. 77 across the whole network.
EVIDENCEMeasured facts: word count, the page’s real code blocks (labelled Exhibit A, B, C…), and its real screenshots pinned as photos.
KNOWN ASSOCIATESThe pages this page links to, and the pages that link back to it.
COLD CASEA page that no other page links to. There are 50 of them in the cabinet.
The outfitsCommunities detected in the link graph: clusters of pages that cite each other more than anyone else. The percentage tells you how many members actually live in the outfit’s dominant sidebar section.
The night shiftPages with commits made after 22:00, straight from the git log.

Every line of narration restates measured data or quotes the pages themselves. The trench coat is decorative. The facts are not.
