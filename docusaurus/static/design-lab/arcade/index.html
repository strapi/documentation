HOW THIS READS

The character is your reading cursor.

  • Doors are the links. Each one stands at the point in the prose where the link is written. Walk to it and press E to follow it.
  • Every object is a block. Jade decking is a code block, a scaffold is a table, a terminal is an endpoint, a billboard is a screenshot.
  • Warnings hit back. A caution knocks you backwards. A tip or a note springs you up.
