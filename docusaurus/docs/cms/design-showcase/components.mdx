Every admonition type is shown below, each containing text, a bullet list, a link, inline code, a link wrapping inline code, and a fenced code block, to demonstrate rich rendering inside.

:::note
This is a **note** admonition with text, `inline code`, a [link](https://strapi.io), and a [link with `inline code`](https://docs.strapi.io).

- A bullet inside a note
- Another bullet

```js
// A code block inside a note
const strapi = require('@strapi/strapi');
```
:::

:::tip Custom tip title
This is a **tip** admonition. It can contain `inline code`, a [link](https://strapi.io), and a [link with `inline code`](https://docs.strapi.io).

- Bullet one
- Bullet two

```bash
yarn strapi develop
```
:::

:::info
This is an **info** admonition with `inline code` and a [link with `inline code`](https://docs.strapi.io).

```json
{ "enabled": true }
```
:::

:::caution Heads up
This is a **caution** admonition.

- Watch out for this
- And this

```ts
const x: number = 42;
```
:::

:::warning
This is a **warning** admonition (custom keyword re-enabled in Strapi docs).

```js
console.warn('Be careful');
```
:::

:::danger
This is a **danger** admonition with a [link with `inline code`](https://docs.strapi.io).

```bash
rm -rf ./build
```
:::

:::strapi Strapi feature
This is the custom **strapi**-branded admonition.

- Strapi-specific note
- With a [link](https://strapi.io)

```js
export default { /* config */ };
```
:::

:::prerequisites
- Node.js installed (see [requirements](/cms/installation))
- A running Strapi project created with `npx create-strapi-app`
- Basic knowledge of `REST` or `GraphQL`
:::
