:::caution Strict types are in beta
Strict types are off by default and do not change how Strapi runs: they only change how TypeScript checks your code. A minor release can tighten the types, so a project that compiles today may report new type errors after an upgrade. Share feedback in the <ExternalLink to="https://github.com/strapi/strapi/discussions/27747" text="strict types GitHub discussion"/>.
:::
